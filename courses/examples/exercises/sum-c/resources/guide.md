# Integer input and output

Read two values with `scanf("%d %d", &a, &b)` and check for a return value of `2`.
Whitespace in the format accepts spaces, tabs, and newlines.
Print only the result and a newline. The stated bounds keep the sum in a
32-bit signed integer.

Useful checks: `-4 7` gives `3`, `0 0` gives `0`, and `-5 -8` gives `-13`.
